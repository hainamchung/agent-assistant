# Code Assistants — Platform Adapter Directory

> Each subdirectory contains **platform-specific adapter files** that the CLI installer uses when installing for a particular AI coding assistant.

## Adapter Contract

| Adapter | Purpose | Files | Generated By |
|---------|---------|-------|-------------|
| `cursor-assistant/` | Custom rules for Cursor | MDC rule files | CLI install |
| `copilot-assistant/` | Agent definition for Copilot | Agent .md files | CLI install |
| `antigravity-assistant/` | Global agent + GEMINI.md for Antigravity/Gemini | Agent .md + config | CLI install |
| `claude-assistant/` | CLAUDE.md entry point for Claude Code | Entry point .md | CLI install |
| `codex-assistant/` | Full TOML mirror for Codex CLI | TOML agents + skill dirs | CLI install |
| `qwen-assistant/` | QWEN.md entry point for Qwen | Entry point .md | CLI install |

## File Count Asymmetry

| Adapter | Files | Reason |
|---------|-------|--------|
| cursor-assistant | 2 | Cursor uses MDC rules — minimal adapter |
| copilot-assistant | 2 | Copilot reads agent definitions directly |
| antigravity-assistant | 2 | Gemini uses global agent file + GEMINI.md |
| claude-assistant | 1 | Claude Code reads CLAUDE.md entry point only |
| codex-assistant | **129** | Codex requires TOML-format agents + skill directory structure |
| qwen-assistant | 1 | Qwen reads QWEN.md entry point only |

The 129:1 ratio between Codex and Claude adapters is **by design**, not a bug:
- Codex CLI uses TOML config format instead of Markdown
- Each agent must be a separate `.toml` file (21 agents)
- Each command must be a skill directory with `instructions.md` + `skill.json` (~53 commands × 2 files)
- The CLI generates these TOML/JSON files from canonical Markdown sources during install

## Maintenance Notes

- **Canonical source**: Always edit agents in `agents/*.md` and commands in `commands/`. Never edit adapter files directly.
- **Codex TOML files**: Auto-generated by `cli/install.js` during `installCodex()`. If agents or commands change, re-run `npm run install:codex`.
- **Drift risk**: Codex adapter files are committed to git (for npm publish). They can become stale if the generation script isn't re-run after canonical source changes.

## Sync Verification

After modifying canonical sources (`agents/*.md`, `commands/**/*.md`), verify adapter sync:

```bash
# Regenerate codex adapter files and check for git diff
npm run install:codex
git diff --stat code-assistants/codex-assistant/

# If diff is non-empty, the adapters were stale — commit the update.
# If no diff, adapters are in sync.
```

> **CI recommendation**: Add `npm run install:codex && git diff --exit-code code-assistants/` to CI to catch drift automatically.

# API Term Mapping

> **Purpose**: Mapping between business domain terms and their technical representations in the codebase.
> **Parent**: [00-index.md](./00-index.md)
> **Last Updated**: 2026-04-09

---

## Overview

Agent Assistant has no HTTP API. The "API" is the set of document-based interfaces that components agree to follow. This file maps business terms to their technical representations in the filesystem, YAML schema, and script interfaces.

---

## Agent Terms → Technical Representation

| Business Term | Technical Field | File Location | Type |
|---------------|----------------|---------------|------|
| Agent name | `name` | `agents/{name}.md` frontmatter | string |
| Agent role | `description` | `agents/{name}.md` frontmatter | string |
| Agent category | `category` | `agents/{name}.md` frontmatter | enum: execution, meta, investigation, validation, research, support |
| Agent profile (HSOL) | `profile` | `agents/{name}.md` frontmatter | `{domain}:{category}` string |
| Agent handoffs | `handoffs` | `agents/{name}.md` frontmatter | string[] |
| Agent scope | `scope.files`, `scope.tasks`, `scope.restrictions` | `agents/{name}.md` frontmatter | string[] |
| Agent guardrails | `guardrails` | `agents/{name}.md` frontmatter | string[] |
| Agent voice | `voice.adaptation`, `voice.deviation_tolerance` | `agents/{name}.md` frontmatter | boolean, number (0-3) |
| Agent trust scope | `role-scope` | `agents/{name}.md` frontmatter | enum: implementation, coordination, analysis, review, research, support |

## Command Terms → Technical Representation

| Business Term | Technical Field | File Location | Type |
|---------------|----------------|---------------|------|
| Command name | filename | `commands/{cmd}.md` | Markdown file |
| Command variant | subdirectory file | `commands/{cmd}/{variant}.md` | Markdown file |
| Phase assignment | Phase section with `Agent:` field | Variant workflow files | Markdown structure |
| Exit criteria | Checklist in phase section | Variant workflow files | Markdown checklist |
| Topology reference | `topology:` in frontmatter | Command/variant frontmatter | string |

## Skill Terms → Technical Representation

| Business Term | Technical Field | File Location | Type |
|---------------|----------------|---------------|------|

## Platform Terms → Technical Representation

| Business Term | Technical Field | File Location | Type |
|---------------|----------------|---------------|------|
| Platform | Key in platforms | `platforms.json` | JSON object |
| Entry point | Generated file | `{PLATFORM_NAME}.md` (root) | Markdown file |
| Entry point template | Source | `AGENT.template.md` | Mustache template |
| Install target | Platform directory | `~/.{tool}/skills/agent-assistant/` | Filesystem directory |
| Platform installer | Function | `cli/lib/platforms/{tool}.js` | JavaScript function |

## CLI Interface Terms → Technical Representation

| Business Term | CLI Command | Script | Output |
|---------------|------------|--------|--------|
| Install framework | `agent-assistant install {tool}` | `cli/install.js` | Files in `~/.{tool}/skills/agent-assistant/` |
| Uninstall framework | `agent-assistant uninstall {tool}` | `cli/install.js` | Removes installed files |
| List platforms | `agent-assistant list` | `cli/install.js` | Installed platform status |
| Create agent | `agent-assistant create agent` | `cli/create.js` | New agent file from template |
| Create command | `agent-assistant create command` | `cli/create.js` | New command router + variants |
| Validate agents | `npm run lint:agents` | `scripts/lint-agents.js` | Lint report (0 errors = pass) |
| Simulate agents | `npm run simulate` | `scripts/simulate.js` | Simulation report (all PASS) |
| Check word budget | `npm run wordcount` | `wc -w rules/RUNTIME.md` | Pass/fail (≤3200 words) |
| Verify trust hashes | `npm run trust:verify` | `scripts/generate-trust-hashes.js` | Hash verification report |

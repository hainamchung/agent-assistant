## Mission

Turn one AI coding assistant into a governed engineering organization. Provide a global, install-once orchestration framework that gives every project access to specialist agents, structured workflows, adversarial collaboration, and quality enforcement across all major AI coding platforms.

## Vision

Every AI-assisted engineering workflow should have the rigor of a professional team, regardless of the tool or project.

## Value Proposition

| For | Agent Assistant Provides |
|-----|--------------------------|
| Individual developers | 21 specialist agents instead of one generalist, structured workflows instead of ad-hoc prompting, adversarial review instead of self-review |
| Teams | Consistent tooling across projects and platforms, quality gates, security guardrails, and auditable decision trails |
| Organizations | Global install eliminates per-project setup, cross-platform parity reduces tool fragmentation, trust tiers manage extension risk |

## Target Outcomes

| Outcome ID | Outcome | Measurement |
|------------|---------|-------------|
| TO-001 | Eliminate per-project AI setup ceremony | Zero configuration files needed per-repo after global install |
| TO-002 | Replace self-review with adversarial quality assurance | Golden Triangle teams produce consensus-stamped deliverables with independent review |
| TO-003 | Reduce context window waste | Tiered loading (NANO/MICRO/FULL) loads only necessary protocol; measured by `measure-context.js` |
| TO-004 | Enable resumable AI workflows | Checkpoint-resume protocol prevents restart-from-zero on interruption |
| TO-005 | Unify workflow model across AI platforms | Same 17 commands, 21 agents, and execution model work across Cursor, Copilot, Claude, Codex, Antigravity, Qwen |
| TO-006 | Automate domain expertise injection | HSOL resolves 1430 skills by agent profile without manual prompt engineering |

## Product Positioning

Agent Assistant is **operational infrastructure for AI-assisted engineering**, not a prompt library or chatbot enhancement. It occupies the layer between the AI model and the developer, adding structure, specialization, and opposition that raw model usage lacks.

**Category**: Developer tooling — AI orchestration framework
**Distribution**: npm global package + companion documentation website
**Competitive differentiation**: Multi-agent with adversarial review, global install, cross-platform parity, 12 execution topologies

## Storage Model

Agent Assistant uses a **file-first** data model with no database. All data is stored as files on the filesystem:

| Data Type | Format | Location | Mutability |
|-----------|--------|----------|------------|
| Agent definitions | Markdown + YAML frontmatter | `agents/*.md` | Static (PR-based) |
| Command workflows | Markdown | `commands/**/*.md` | Static (PR-based) |
| Protocol rules | Markdown | `rules/*.md` | Static (PR-based) |
| Skill registries | YAML | `matrix-skills/*.yaml` | Static + Dynamic |
| Skill definitions | Markdown | `skills/*/SKILL.md` | Static (PR-based) |
| Platform config | JSON | `platforms.json` | Static (PR-based) |
| Release config | JSON | `.releaserc.json` | Static (PR-based) |
| Patterns | JSON | `global-patterns.json` | Runtime (appended) |
| Generated cards | JSON | `a2a-cards/*.json` | Generated (script) |
| Trust hashes | JSON | Trust manifest | Generated (script) |

## Agent Schema (YAML Frontmatter)

Defined in `schemas/agent-schema.md`, validated by `scripts/lint-agents.js`:

```yaml
---
schema-version: "1.0"           # Required: Schema version
name: backend-engineer           # Required: Unique identifier
description: "..."               # Required: One-line role description
profile: "backend:execution"     # Required: {domain}:{category}
skill-profile: "REST API"        # Required: Primary skill keyword
handoffs: [tester, devops-engineer]  # Required: Agent handoff targets
version: "1.0"                   # Required: Definition version
category: execution              # Required: execution|meta|investigation|validation|research|support
role-scope: implementation       # Required: implementation|coordination|analysis|review|research|support
personality:
  tone: technical                # technical|friendly|neutral|academic
  verbosity: concise             # concise|moderate|verbose
  style: pragmatic               # pragmatic|thorough|creative|analytical
  humor: none                    # none|light|moderate
capabilities:                    # Required: Capability keywords
  - api-development
  - server-logic
scope:
  files: ["src/**", "lib/**"]    # Required: File access globs
  tasks: [implementation]        # Required: Allowed task types
  restrictions: [no-frontend-changes]  # Required: Forbidden actions
guardrails:                      # Required: Applied guardrail modules
  - injection-defense
  - output-sanitization
  - io-pipeline
voice:
  adaptation: true               # Voice coherence adaptation
  deviation_tolerance: 1         # Allowed deviation level
preflight:                       # Required: Pre-execution checks
  - implementation_target_identified
  - prior_phase_deliverables_present
  - token_budget_ok
---
```

**Validation Rules** (enforced by `lint-agents.js`):
- R001–R099: Required field checks
- R100–R199: Type validation
- R200–R299: Cross-reference validation (handoff targets exist, guardrails exist)
- R300–R302: Security checks (role-scope boundaries, trust manifest, quarantine)

## Platform Configuration Schema (JSON)

From `platforms.json`:

```json
{
  "copilot": {
    "name": "GitHub Copilot",
    "tool_path": ".copilot",
    "boot_file": "COPILOT.md",
    "capabilities": {
      "sub_agents": true,
      "terminal": true,
      "file_edit": true,
      "web_search": true,
      "mcp": true
    },
    "adapter_hints": {
      "default_tier": "MICRO",
      "execution_model": "hybrid",
      "max_context": 128000,
      "sub_agent_tool": "runSubagent"
    },
    "formatting_hints": {
      "markdown_tables": true,
      "code_blocks": true,
      "mermaid": false
    }
  }
}
```

**Schema fields**:
| Field | Type | Description |
|-------|------|-------------|
| `name` | string | Display name |
| `tool_path` | string | Home directory subfolder |
| `boot_file` | string | Entry file name |
| `capabilities` | object | Boolean feature flags |
| `adapter_hints` | object | Default runtime settings |
| `formatting_hints` | object | Output format support |

## Trust Manifest Schema

Generated by `scripts/generate-trust-hashes.js`:

| Field | Type | Description |
|-------|------|-------------|
| File path | string | Relative path to the file |
| SHA-256 hash | string | Integrity hash |
| Trust tier | enum | core, verified, community |
| Generated at | ISO timestamp | Generation time |

**Purpose**: Integrity verification for installed framework files. Ensures files haven't been tampered after installation.

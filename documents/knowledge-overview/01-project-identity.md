## Purpose and Mission

Agent Assistant turns one AI coding assistant into a governed engineering organization. Instead of relying on a single generalist AI that writes, reviews, and ships its own code, Agent Assistant introduces specialization, structured workflows, adversarial review, and quality gates — the same principles that make real engineering teams effective.

**Vision**: Every AI-assisted engineering workflow should have the rigor of a professional team, regardless of the tool or project.

**Mission**: Provide a global, install-once orchestration framework that gives every project access to specialist agents, structured workflows, adversarial collaboration, and quality enforcement across all major AI coding platforms.

---

## Problem Statement

Most AI coding workflows break when tasks become real:

1. **Single-voice problem**: One AI generates code, reviews its own code, explains its own decisions, and ships — no meaningful opposition
2. **Per-project ceremony**: Every new repo needs the same setup, same knowledge injection, same prompt engineering
3. **Context tax**: Domain expertise must be re-taught through prompt repetition; complex tasks exhaust context windows
4. **Self-review theater**: Reviews are often self-review disguised as rigor, with no independent challenge
5. **Restart-from-zero**: Interrupted workflows lose all progress
6. **Platform fragmentation**: Different AI tools require different approaches, preventing unified workflows

## First 60 Minutes Onboarding

### Minute 0–10: Understand the Project
1. Read `README.md` — understand the problem, solution, and command surface
2. Scan the 3 execution modes: `:fast`, `:hard`, `:team`
3. Understand the Golden Triangle concept (tech-lead + executor + reviewer)

### Minute 10–20: Install and Verify
1. Install: `npm install -g @namch/agent-assistant@latest`
2. Install for your AI tool: `agent-assistant install copilot` (or cursor/claude/etc.)
3. Verify: Open your AI tool and try `/help` to see available commands

### Minute 20–35: Explore the Framework
1. Browse `agents/` — read 2-3 agent files (e.g., `backend-engineer.md`, `reviewer.md`)
2. Browse `commands/` — read a router file + one variant (e.g., `cook.md` → `cook/fast.md`)
3. Read `rules/RUNTIME.md` — understand the tiered loading protocol and orchestration laws

### Minute 35–50: Try a Workflow
1. Open any project in your AI tool
2. Run `/docs:core` to generate project documentation
3. Run `/cook:fast "add a simple feature"` to see the build pipeline
4. Run `/review "check recently changed files"` to see adversarial review

### Minute 50–60: Development Setup (for Contributors)
1. Clone: `git clone https://github.com/hainamchung/agent-assistant.git && cd agent-assistant`
2. Install: `npm install`
3. Validate: `npm run ci:local` (should pass with 0 errors)
4. Read `CONTRIBUTING.md` for standards and PR process

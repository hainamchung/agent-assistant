## Multi-Agent Orchestration

The framework defines 21 specialist agents, each with a distinct expertise area, role category, and behavioral constraints.

**Agent Categories**:
- **Execution**: backend-engineer, frontend-engineer, mobile-engineer, game-engineer — implement code
- **Meta**: tech-lead, project-manager — coordinate and decompose tasks
- **Investigation**: debugger, scouter, performance-engineer — analyze and discover
- **Validation**: reviewer, tester — adversarially verify quality
- **Research**: researcher, brainstormer — explore options and generate ideas
- **Support**: docs-manager, reporter, designer, business-analyst, database-architect, devops-engineer, security-engineer, planner — specialized support

Each agent is defined as a Markdown file with YAML frontmatter containing: role, category, triggers, skills, guardrails, protocols, handoffs, and evaluation criteria.

## Command System

17 top-level command routers with variant workflows provide structured task execution.

**Execution Modes**:
| Mode | Suffix | Characteristics |
|------|--------|----------------|
| **Fast** | `:fast` | Minimal phases, solo execution |
| **Hard** | `:hard` (default) | Full phases, thorough analysis |
| **Team** | `:team` | Golden Triangle adversarial collaboration |

**Command Routing**: Commands are routed via explicit prefixes (`/cook`, `/fix`, `/test`) or natural language mapping ("fix this bug" → `/fix`). Each router file dispatches to the appropriate variant.

## Hybrid Skill Orchestration Layer (HSOL)

The HSOL auto-resolves domain skills based on agent profiles and task context. Skills are organized in a 3-tier hierarchy:

1. **Matrix Skills** (`matrix-skills/`): 1430 skills in 19 domain registries — predefined mappings
2. **Library Skills** (`skills/`): 1400+ deep skill directories with SKILL.md definitions
3. **Dynamic Skills** (`_dynamic.yaml`): Community-installable skill extensions

**Domains**: backend, frontend, mobile, security, cloud, devops, database, testing, performance, ai-ml, architecture, design, analytics, game-dev, blockchain, iot, embedded, accessibility, localization.

Skills are resolved at task start based on agent role + detected tech stack + project type signals.

## Golden Triangle Teams

17 domain-specific teams using the adversarial golden-triangle topology:

Each team consists of: **Tech Lead** (decomposes & coordinates) + **Executor** (implements) + **Reviewer** (adversarially challenges)

Teams: backend, frontend, fullstack, mobile, api, database, security, devops, cloud, testing, performance, ai-ml, design, game, data, architecture, documentation.

The adversarial review ensures that the executor's work is independently challenged before acceptance.

## Guardrails and Security

7 behavioral guardrail modules enforced via agent frontmatter:

| Guardrail | Scope |
|-----------|-------|
| **injection-defense** | Prompt injection prevention |
| **output-sanitization** | Content safety and redaction |
| **io-pipeline** | 4-stage I/O validation pipeline |
| **auth-patterns** | Authentication/authorization enforcement |
| **data-privacy** | PII handling and data protection |
| **resource-limits** | Token budget and resource constraints |
| **violation-escalation** | Escalation protocol for violations |

**Security Features**:
- D4 Security dimension in 5-dimension evaluation (overrides all others)
- Trust tiers: core (SHA-256 verified) → verified → community
- Role-scope boundaries: agents can only access their declared scope
- OWASP-aligned security checks in CI pipeline

## Tiered Context Loading

The RUNTIME.md loading protocol uses three tiers to optimize context window usage:

| Tier | Size | Use Case |
|------|------|----------|
| **NANO** | ~500 words | Simple commands, single-agent tasks |
| **MICRO** | ~1500 words | Standard workflows, team coordination |
| **FULL** | ~3200 words | Complex multi-phase, debugging, team execution |

This reduces token spend by up to 85% for simple tasks, keeping context budget for actual work.

## CLI and Global Installation

The CLI tool installs the framework globally and syncs it to each AI coding tool:

```
npm install -g @namch/agent-assistant@latest
agent-assistant install copilot   # installs for GitHub Copilot
agent-assistant install cursor    # installs for Cursor
agent-assistant install --all     # installs for all detected platforms
```

Features: platform detection, partial installs, file diff checking, progress tracking, wizard mode.

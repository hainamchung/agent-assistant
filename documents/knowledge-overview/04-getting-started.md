## Prerequisites

| Requirement | Minimum | Recommended |
|-------------|---------|-------------|
| Node.js | 18.0.0 | 20.x LTS |
| npm | Comes with Node | Latest |
| AI Coding Tool | At least 1 supported platform | GitHub Copilot or Claude Code |

**Supported AI Coding Platforms**: Cursor, GitHub Copilot, Claude Code, Codex, Antigravity (Gemini), Qwen.

## Installation (End User)

### Standard Install (npm global)

```bash
npm install -g @namch/agent-assistant@latest
```

### Interactive Wizard

```bash
agent-assistant install
```

The wizard guides you through platform selection, detects installed tools, and installs files.

### Direct Platform Install

```bash
agent-assistant install copilot    # GitHub Copilot
agent-assistant install cursor     # Cursor
agent-assistant install claude     # Claude Code
agent-assistant install codex      # Codex
agent-assistant install gemini     # Antigravity (Gemini)
agent-assistant install qwen       # Qwen
agent-assistant install --all      # All detected platforms
```

### List Installed Platforms

```bash
agent-assistant list
```

### Uninstall

```bash
agent-assistant uninstall copilot  # Remove from specific platform
agent-assistant uninstall --all    # Remove from all platforms
```

## Platform Setup

After installing, the framework creates platform-specific configuration files in your home directory:

| Platform | Installed Path |
|----------|---------------|
| Copilot | `~/.copilot/` |
| Cursor | `~/.cursor/` |
| Claude | `~/.claude/` |
| Codex | `~/.codex/` |
| Antigravity | `~/.antigravity/` |
| Qwen | `~/.qwen/` |

Each platform directory contains:
- Entry file (e.g., `COPILOT.md`) for boot sequence
- `skills/agent-assistant/` directory with agents, commands, rules, skills, and all framework files

---

## First Run

1. Open your AI coding tool in any project
2. The framework auto-activates via the platform entry file
3. Try these commands:

```
/help                           # See all available commands
/cook:fast "add a health check" # Quick feature implementation
/review                         # Review recent changes
/docs:core                     # Generate project documentation
```

## Verification

After installation, verify:

```bash
# Check global install
agent-assistant --version  # Should show version number

# Check platform files
agent-assistant list       # Shows installed platforms with status
```

In your AI tool, verify by asking:
- "What commands are available?" → Should list the 17 commands
- `/help` → Should show the command reference

## Development Setup (Contributors)

### Clone and Install

```bash
git clone https://github.com/hainamchung/agent-assistant.git
cd agent-assistant
npm install
```

### Local Validation

```bash
npm run ci:local
```

This runs:
1. `npm run lint:agents` — Schema validation (frontmatter + rules R001–R302)
2. `npm run simulate` — Static analysis (handoff integrity, skill references)
3. `npm run validate:output` — Deliverable schema validation
4. `npm run wordcount` — RUNTIME.md word budget check (≤3200 words)

All checks must pass before committing (enforced by Husky pre-commit hook).

### Available Dev Scripts

| Script | Purpose |
|--------|---------|
| `npm test` | Run all tests (`node --test`) |
| `npm run lint:agents` | Validate agent/command schemas |
| `npm run simulate` | Static agent simulation |
| `npm run validate:output` | Validate deliverable schemas |
| `npm run wordcount` | RUNTIME.md word budget |
| `npm run ci:local` | Full validation suite |
| `npm run generate:entry-points` | Regenerate platform entry files |
| `npm run generate:a2a-cards` | Generate Agent-to-Agent cards |
| `npm run generate:gallery-data` | Generate web gallery data |

### Web Development

```bash
cd web
npm install
npm run dev      # Start Vite dev server
npm test         # Run Vitest tests
npm run build    # Production build
```

## Common Issues

| Issue | Solution |
|-------|----------|
| `node: command not found` | Install Node.js 18+ from nodejs.org |
| `Permission denied` during install | Use `sudo npm install -g` or fix npm permissions |
| Framework not activating in AI tool | Verify platform files exist: `agent-assistant list` |
| Wordcount check failing | Edit `rules/RUNTIME.md` to stay within 3200 word budget |
| Lint errors on agent files | Run `npm run lint:agents` and fix reported frontmatter issues |

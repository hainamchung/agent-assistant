## Directory Breakdown

### `agents/` — Specialist Agent Definitions

Contains 21 Markdown files, each defining a specialist agent with YAML frontmatter (schema-version 1.0). Each agent has: name, description, profile, category, handoffs, capabilities, scope, guardrails, voice settings, and preflight conditions. The `teams/` subdirectory contains 17 Golden Triangle team compositions.

| Item | Type | Purpose |
|------|------|---------|
| `backend-engineer.md` | file | Backend implementation specialist |
| `frontend-engineer.md` | file | Frontend implementation specialist |
| `tech-lead.md` | file | Architecture and coordination lead |
| `reviewer.md` | file | Independent code reviewer |
| `tester.md` | file | Test creation and quality specialist |
| `scouter.md` | file | Codebase reconnaissance and analysis |
| `docs-manager.md` | file | Documentation architect |
| `teams/` | dir | 17 domain-specific Golden Triangle teams |

### `commands/` — Command Routers and Workflow Variants

Each top-level `.md` file is a command router that dispatches to variant files in subdirectories. Variants include `:fast`, `:hard`, and `:team` for different execution depths.

| Item | Type | Purpose |
|------|------|---------|
| `cook.md` | file | Router for `/cook` (build features) |
| `cook/fast.md`, `hard.md`, `team.md` | files | Variant workflows for /cook |
| `fix.md` | file | Router for `/fix` (bug fixing) |
| `docs.md` | file | Router for `/docs` (documentation suite) |
| `deploy/` | dir | Deploy variants: check, preview, production, rollback |

### `rules/` — Protocol Files

41 protocol documents that define the orchestration operating model. `RUNTIME.md` is the single source of truth loaded at boot. Other files are loaded on-demand.

| Item | Type | Purpose |
|------|------|---------|
| `RUNTIME.md` | file | Core orchestration protocol (≤3200 words, tiered loading) |
| `REFERENCE.md` | file | Quick lookup tables and expanded details |
| `EVALUATION.md` | file | 5-dimension evaluation scoring model |
| `TEAMS-LITE.md` | file | Team assembly rules and signal keywords |
| `SKILLS-LITE.md` | file | Skill resolution protocol |
| `ERRORS.md` | file | Error handling and recovery |

### `cli/` — CLI Tooling

Node.js CLI for installing the framework globally into AI tool home directories. Also includes scaffolding tools for creating new agents, commands, and topologies.

| Item | Type | Purpose |
|------|------|---------|
| `install.js` | file | Main CLI entry point — install/uninstall/list |
| `create.js` | file | Scaffolding tool — create agent/command/topology from templates |
| `lib/` | dir | Shared libraries: config, fs-utils, platforms/, progress, prompts, UI, wizard |

### `scripts/` — DevOps Tooling

30+ validation, generation, and utility scripts. All are Node.js scripts invoked via `npm run` commands.

| Item | Type | Purpose |
|------|------|---------|
| `lint-agents.js` | file | Validates agent/command frontmatter (R001-R302) |
| `simulate.js` | file | Static agent simulation — validates handoffs and structure |
| `validate-output.js` | file | Validates workflow output against deliverable schemas |
| `workflow-regression.js` | file | Regression testing for workflows |
| `generate-entry-points.js` | file | Generates platform entry point files |
| `generate-a2a-cards.js` | file | Generates A2A card JSON from agent files |
| `mcp-server.js` | file | MCP server for external tool integration |
| `lint-rules/` | dir | Modular lint rule modules (security, locale, topology, etc.) |

### `skills/` — Domain Skills Library

~1400+ subdirectories, each containing a `SKILL.md` file. Skills are resolved dynamically via the HSOL (Hybrid Skill Orchestration Layer) based on agent profiles. Organized by domain (backend, frontend, AI/ML, security, cloud, etc.).

### `matrix-skills/` — Skill Domain Registries

21 YAML files that define skill-to-agent mappings. The `_index.yaml` is the central registry; `_dynamic.yaml` handles community-installed skills.

### `web/` — Documentation Website

A React 19 + Vite web application with TypeScript, deployed to Vercel. Includes a gallery page for browsing agents and commands, and documentation pages.

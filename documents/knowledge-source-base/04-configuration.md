## Environment Variables

This project does not use `.env` files for its core functionality. The framework is file-driven and installs via file copy operations. However:

- `.gitignore` includes `.env` and `.env.*` patterns, suggesting environment files may be used in deployment contexts
- The web subproject may use Vite environment variables (`VITE_*`) for the documentation site
- CI/CD uses GitHub Actions secrets for npm publishing and GitHub releases (handled by semantic-release)

---

## Secrets Management

- No application-level secrets exist in the core framework
- Release secrets (npm token, GitHub token) are managed via GitHub Actions secrets
- Trust verification uses SHA-256 hashes (`scripts/generate-trust-hashes.js`) for integrity checking, not secret-based auth
- The `SKILL-SECURITY.md` rule defines trust tiers (core, verified, community) with integrity verification

# Skills Quarantine Directory

Community-submitted skills are placed here for review before promotion.

**Rules:**
- Skills in this directory are NEVER auto-loaded.
- Each skill must pass a maintainer review (code audit, functionality check, schema compliance).
- Approved skills are moved to `skills/` and registered in `skills/trust-manifest.json` as `verified`.
- Rejected skills are removed with a documented reason.

See `rules/SKILL-SECURITY.md` for the full quarantine process and trust level definitions.
